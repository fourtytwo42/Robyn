# Sherwood product film storyboard

## Format

- 1920x1080, 30 fps, 2:45-3:00.
- Real Devnet UI plus deterministic standalone HTML scenes.
- Devnet disclosure remains visible throughout.
- No music; narration and restrained original interface sounds only.

## Capture rules

- Never hide required timing or join unrelated transactions as though they were one continuous wallet state.
- Keep wallet addresses truncated but retain full hashes in sealed evidence.
- Cursor emphasis is visual only and must not cover quote, slippage, or network labels.
- Failed optional maintenance may be demonstrated only if the successful primary action is visibly reconciled.
- Do not record Testnet, Mainnet, operator keys, environment variables, terminal secrets, or administrative sessions.
